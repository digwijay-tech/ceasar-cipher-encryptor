# 🔐 Caesar Cipher Text Encryptor & Decryptor

A simple web application built with **Next.js** that encrypts and decrypts text using the **Caesar Cipher** algorithm. Enter your message, choose a shift value, and instantly convert it into an encrypted or decrypted form.

## Features

- Encrypt text
- Decrypt text
- Custom shift value
- Simple and responsive UI

## Tech Stack

- Next.js
- JavaScript
- Tailwind CSS

## Getting Started

```bash
pnpm install
pnpm dev
